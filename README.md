### [Build visually. Keep the code. →](https://github.com/umarilyas02/OpenForge)

OpenForge is an open-source visual development environment for building,
editing, exporting, and deploying production-grade Next.js applications
without giving up source-code ownership.

- **Source-first by design** — Projects remain normal, readable Next.js code that can be cloned, tested, deployed, and maintained outside the editor
- **Visual and code workflows together** — Responsive canvas editing stays synchronized with validated source changes and reviewable diffs
- **AI without lock-in** — Optional bring-your-own-provider assistance proposes changes for review instead of silently rewriting a project
- **Built for extensibility** — GitHub and Vercel workflows, self-hosting, and a permission-scoped plugin and skills SDK are part of the direction

**Current phase:** establishing the architecture, security boundaries, service
contracts, and contributor workflow in public.
